# Integration integrity validation

This change preserves scalar canonical facts when an operator supplies a nested path, rejects
ambiguous operator paths, treats operator unit maps as atomic path declarations, and retains unit
conflicts. Partial drawing floor labels cannot certify total building floor/basement counts.

Assertion AEC subjects persist through migration 008 and source-evidence queries. A changed project,
object or revision scope creates a fresh unreviewed candidate identity. Empty legacy scopes retain
their existing identity. The rule compiler and evaluator check explicit units and finite numerical
values, including older compiled rules whose units lived only in branch metadata.

All legal examples in tests are synthetic. The offline CLI explicitly reports non-binding mode and
does not manufacture canonical approval metadata. No actual law dataset was created or promoted.
No live PostgreSQL, Docker, API, worker or model state was changed. PostgreSQL migration/readback
tests use the disposable service configured in GitHub CI, not the live Ontology database.
