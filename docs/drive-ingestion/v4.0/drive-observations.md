# 익명화된 Drive 자료 유형 관찰

이 기록은 이전에 확인한 일부 대표 폴더의 자료 유형을 설계 요구사항으로 일반화한 것이다. 프로젝트명·주소·Drive URL·파일 ID는 제거했다. 전체 Drive 통계가 아니며, v4 감사에서 원본 파일을 다시 파싱한 결과도 아니다.

| 자료 유형 | 관찰된 조합 | 설계에 주는 의미 |
|---|---|---|
| 프로젝트 설계 자료 | 작업·허가·실시·착공·감리 단계에 DWG, BAK, 잠금 파일, SKP, 개별 시트 PDF와 합본 PDF가 함께 존재 | 도면 외 백업·잠금·출력본을 인벤토리에 남기고 상태와 사용 목적을 구분한다. |
| 발행 및 수정 자료 | 날짜가 다른 DWG와 PDF, 시공사 전달 후 수정된 파일이 공존 | Drive 수정 시각, 도면 표제란 개정일, 발행·전달 이벤트를 분리한다. |
| 대수선·추인 자료 | 변경 전후 도면, 건축물대장 도면, 구조·소방 검토서, 분할 PDF, 합본, ZIP이 함께 존재 | 사업 유형, 현황 상태, 보완 회차, 제출 패키지와 압축 내부 파일의 계보가 필요하다. 체크리스트는 최종 적합 판정이 아니다. |
| SketchUp 자료 | 날짜별 옵션·변경안과 재사용 참고 모델이 함께 존재 | 프로젝트 대안과 공용 부품·참고 컬렉션을 나눈다. 메타데이터만으로 geometry·scene 추출을 입증하지 않는다. |
| 규정·검토 자료 | 지자체 제출 체크리스트, 관련 법령, 제출서류 표와 규칙 엔진 설계 문서가 존재 | 기존 자료를 규칙·체크리스트 후보로 연결하되, 설계 문서를 승인된 운영 규칙으로 오인하지 않는다. |

서로 다른 원본 ID의 제목이 비슷하거나 Drive revision만으로 설계 변경 흐름을 복원할 수 없는 경우가 있다. 원본 identity, 동일 바이트, 파생 관계, 논리 문서와 실제 발행 이벤트를 별도 관계로 보존한다. Drive 전체의 파일 수·형식 비율·건축 관련 문서 수·파싱률은 전수 인벤토리 후에만 산출할 수 있다.
